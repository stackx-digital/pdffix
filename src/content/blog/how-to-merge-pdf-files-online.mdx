Need to combine several PDF documents into a single file? Whether you're assembling a report, combining invoices, or merging chapters of a book — merging PDFs takes just seconds with the right tool.

## When Do You Need to Merge PDFs?

Common reasons to combine PDFs:

- **Work reports** — Combine multiple department reports into one master document
- **Invoices & receipts** — Bundle monthly expenses for accounting
- **Contracts** — Merge cover letters, agreements, and appendices
- **Academic work** — Combine research papers or assignment sections
- **Portfolios** — Assemble a PDF portfolio from individual project files

## Can I Reorder Pages After Merging?

Yes. After merging, you can use the [Organize PDF](/tools/organize-pdf) tool to rearrange individual pages — including pages from different source files.

## Tips for Merging PDFs

**Check page orientation first**  
If some files are landscape and others portrait, the merged PDF will mix orientations. Consider rotating pages using the [Rotate PDF](/tools/rotate-pdf) tool before merging.

**Remove unwanted pages beforehand**  
Use the [Delete Page](/tools/delete-page) tool to remove unwanted pages from each file before combining them.

**Compress after merging**  
A merged file can be large. Run it through [PDF Compress](/tools/compress-pdf) to reduce size before sharing.

## Merging vs. Inserting Pages — What's the Difference?

| Action | Use When |
|---|---|
| Merge PDF | Combining complete documents end-to-end |
| Insert pages | Adding specific pages from one doc into another |
| Organize PDF | Reordering pages within a single document |
