If you've ever tried to email a PDF only to get a "file too large" error, you're not alone. PDF compression is one of the most common tasks people need — and the good news is you don't need to install any software to do it.

## Why Are PDFs So Large?

PDFs can be large for several reasons:

- **Embedded images** — High-resolution photos add significant file weight
- **Embedded fonts** — Custom fonts are stored inside the file
- **Unused objects** — Deleted content can leave invisible data behind
- **Multiple revisions** — Editing history can bloat the file

## How PDF Compression Works

There are two types of PDF compression:

### Lossless Compression
Removes unused objects and redundant data without affecting visual quality. This is the safest method and works well for text-heavy documents.

### Lossy Compression
Reduces image quality to shrink file size further. Useful when you need a very small file and image sharpness isn't critical.

## Tips to Keep File Size Small

- **Use PDF/A format** for archival documents — it's optimised for size
- **Flatten annotations** before sharing — editable annotations add weight
- **Resize images before inserting** — don't rely on PDF to do it
- **Remove unused pages** using a [PDF page deletion tool](/tools/delete-page)
